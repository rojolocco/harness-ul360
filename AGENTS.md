# Revista: Urgencias Lean 360

## Descripcion General

Urgencias Lean 360 es una revista de medicina de urgencias, orientada a la produccion de conocimiento en las areas de innovacion y tecnologia, aplicadas a está area de la medicina.

## Proposito de este proyecto

En este repositorio se trabajara en los siguientes temas:

- Creacion de articulos para la revista
- Creacion de articulos para blog

## Estructura PARA

En este repositorio se usara una estructura PARA, para la creacion de un segundo cerebro de la revista.

## Carpeta /scripts

En la carpeta scripts se crearan los scripts en lenguaje python necesarios por las Skills de este repositorio.
